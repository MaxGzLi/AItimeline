# AITimeline 刘海应用

macOS 刘海里的一块常驻面。三档,**每档只回答一个问题,三档不重复**:

| 档 | 面板尺寸 | 回答什么 | 放什么 |
|---|---|---|---|
| 静默条 | 295×36 | 眼下最急的那样东西怎么样了 | 刘海左边一个记号,右边一个数 |
| 小条(悬停 0.3 秒) | 408×88 | 这一件是什么、为什么现在给我看,**外加一排切面按钮** | 让位带里放元信息,下面一个方块加**一句**话,右端五个按钮 |
| 半屏面板(点一下) | 900×520 | 一整件事 | 左边主栏,右边 236 宽的侧栏 |

小条**不放正文**。刘海上读半句被截断的话最没用 —— 它的活是让人在 0.3 秒里决定点不点开。

## 五个面

半屏面板上肩栏左边一排图标切面,悬停小条的内容行右端也有同一排(小一号)。
**五个面骨架完全一样**(主栏 / 竖线 / 右 236),切面的时候两条竖线纹丝不动 ——
换的是内容,不是版式。

| 面 | 主栏 | 侧栏 | 数据从哪来 |
|---|---|---|---|
| AI 进程 | 哪几个 Claude Code 会话在跑 | 三种状态各几个、这数据怎么来的 | Claude Code 钩子写的文件,全在本机 |
| 知识 | 一整张卡的正文 | 复习问题、概念、章节、来源 | 本机 `127.0.0.1:8787/api/inject/cards` |
| 收集 | 拖进来的东西和它们的下场 | 三种东西各会变成什么、什么存不下 | 拖放;发到 `/api/captures/source` 和 `/api/notes` |
| 专注 | 番茄钟本体 | 今天几轮、这钟的规矩 | 全在本机,`UserDefaults` |
| 日程 | 月历 + 选中那天的安排 | 现在几点、往后七天 | 系统日历(EventKit,只读) |

**切面按钮在悬停这一档就得有。** 原版不是这样 —— 它悬停档只能靠落水槽里的左右箭头
一个一个翻模块,想直接去日程得先点开面板。用户的原话是「还得点进去才能切换是很差的
用户体验」,所以这里比原版多一排。按钮放在**内容行右端**不放肩栏:小条 408 宽,
肩栏两翼各只有 82(两边 20 的内边距,中间还要让开刘海那 203),五个按钮塞不下,
硬塞就有一截压在刘海底下 —— 那块屏幕物理上不显示,等于按钮丢了。

**静默条同时只显示一个面**,顺序钉死在 `StripPriority`,规矩是**「正在动的压过站着不动的」**:

1. Claude Code 在跑或者停下来等你 —— 排头一个。只有它会**卡着不动等你**,
   你不回话它就一直停在那儿;别的几样都是你什么时候看都行;
2. 番茄钟在跑 —— 一秒一跳,不看白跑;
3. 一刻钟内有日程 —— 不看要迟到;
4. 收集架上有东西在路上 —— 刚扔进去的,得让人看见它落没落地;
5. 都没有,才是知识卡的数 —— 它是一堆**攒着的**,明天看也一样。

知识卡排最后是有意的:静默条不是「文章栏」,是「现在有什么在动」。
翻卡片是放大以后的事,静默条上一张卡都不许自己换。
条上显示的是哪个面,掉下来就得是哪个面,不然那一条就是骗人的。

第 3 条要成立,状态得自己会变:`ShelfStore` 只要还有东西在路上就 20 秒对一次接口,
落地了自己停。不然一条早转化完的东西会一直挂着说「排队中」,静默条就赖着不还给知识卡。

### AI 进程面怎么知道 Claude Code 在干什么

Claude Code 每走一步会执行钩子。钩子就干一件事:**把标准输入原样落成一个文件**,
刘海盯着那个目录收,收完删掉。

```
Claude Code 钩子 --写文件--> ~/Library/Application Support/AITimelineNotch/agents/ --看目录--> 刘海
```

**这里跟原版不一样,而且是更省的一种做法。** 原版的扩展跑在 JS 沙箱里,碰不到文件系统,
所以它得拿 Python 起一个本地 HTTP 服务当桥,钩子用 `curl` 往 `127.0.0.1:7823` 发。
我们是原生应用,文件随便读 —— 少一个 Python 进程、少一个端口、少一个「桥没起来」的故障档。

文件的形状是**头一行状态,剩下是钩子原样的 JSON**。状态由脚本参数给,不从 JSON 里猜:
少依赖一个字段就少一处会坏的地方。事件和状态的对法照原版:
`UserPromptSubmit`/`PreToolUse`/`PostToolUse` → 在干活,`Notification` → 等你回话,
`SessionStart`/`Stop` → 闲着,`SessionEnd` → 划掉。

干着活但半分钟没动静的自动降成「闲着」—— 钩子崩了不能让一个会话永远挂着「在干活」。
半小时没消息的会话从列表里划掉。

**不自己动 `~/.claude/settings.json`。** 那是用户自己的配置文件,得他在面板上按了
「接上 Claude Code」才写,写之前先存一份 `.aitimeline-bak`。加进去的每条命令都带
`# aitimeline-notch` 记号,「拆掉钩子」只删带记号的那几条,用户自己配的一条不碰。
钩子脚本落在 Application Support 里、**不放在应用包里** —— 应用挪个位置,
写进 `settings.json` 的路径就断了。

只知道「哪个目录、在干活还是等你」。不读对话内容,不联网。

### 收集面收什么

- **链接** → `POST /api/captures/source`(`intakeKind: browser_share`)→ 走完整通路,出带引文的知识卡。
- **纯文字** → `POST /api/notes`(`kind: idea`)→ 存成**笔记**,不过来源质量门禁、不过引文接地检查。
- **截图** → 本机 Vision 认字,再当文字走上面那条。接口只收 JSON、没有图片上传口,
  模型也不在客户端这边,所以今天只能到这一步。
- **存不下的**:本地文件(出处地址该写什么还没定)、私网地址。

条目状态从 `GET /api/source-candidates` 对回来。注意返回的形状是
`{ records: [{ status, candidate: { source: { url } } }] }` —— 网址埋在两层里面。
`rejected_source` / `unreachable` / `skipped` 都是**终局**,同一个网址再发一次接口只会回
「这个我知道」,所以这几种不给重试按钮,只有「压根没送出去」才给。

数据全部走本机,不外发。接口挂掉时保留上一批卡,只把静默条压暗 —— 知识卡不会一分钟就过期,
拿旧的看比空着强,也不需要弹个橙色警告吓人。
「标记已复习」回传一条行为信号到 `127.0.0.1:8787/api/signals`,和浏览器插件同一个接口同一套字段。

## 构建和运行

```bash
brew install xcodegen          # 只需一次
cd apps/notch
xcodegen                       # 从 project.yml 生成 .xcodeproj
xcodebuild -scheme AITimelineNotch -configuration Release -derivedDataPath build build
open build/Build/Products/Release/AITimelineNotch.app
```

退出:菜单栏那个书本图标 → 退出。

## 排版语法(改界面前必读)

`Sources/Core/DesignTokens.swift` 三张表是从 SuperIsland 源码里量出来的,不是随手取的。
三条纪律:

1. **字号只有七档**:9.5 / 10 / 11 / 12 / 13 / 15 / 22。量出第八个值就是破规矩了。
2. **全篇只有白色加透明度台阶**,唯一的彩色是琥珀 `(255,184,51)`,**只绑「轮到你动手了」**。
   现在有两处用它:知识卡「该复习」,和 AI 进程「等你回话」—— 这两件是同一件事。
   深色界面上乱撒颜色是 AI 感最重的一种做法。原版 AI 进程是紫/黄/绿/红四色,
   番茄钟是橙/绿/红三色,我们一概不抄:状态的区别靠字说清楚。
3. **一段文字绝不排满内容宽。** 面板 900 宽,正文最长一行 544。一行横穿 836 点,
   眼睛读到行尾找不回行首 —— 这是「排版跟屎一样」的头号原因,加内边距救不了,
   得切栏。原版 658 宽的面板也是切三栏的。

留白靠**绝对像素**不靠百分比:小条左右各留 34(408 宽里内容占 83%),
半屏面板的左右留白**是算出来的**(`AppState.contentSidePadding` = 侧墙位置 + 16),
有刘海的机器上是 26,没刘海的是 56 —— 两种机器可用宽度不一样,见下面第六条坑。
主栏宽度跟着变:没刘海 511,有刘海 571。
百分比会在窄档显得挤、宽档显得空。

其它几条具体的:
- **小节标题比正文更小更淡**(11pt / 0.52 压 13pt / 0.68)。反过来的话,六个小节读下来全是标题在叫。
- **节内 5、节间 20**,1:4 的呼吸比。从头到尾一个间距值 = 一堵墙。
- **挂式缩进**:正文左边界统一钉在栏内 15,锚点竖条挂在 0。用户说的「没空档」,
  一半是没有一条竖直的对齐线可看,眼睛无处落脚。
- **要点必须和大标题长得不一样**:22 粗体紧跟一行 15 粗体,看着就是同一句话说了两遍。
  加一根竖条、字重降到 medium,它才变成注解。
- **两翼一律按公式算**:中间净空 = 刘海宽 + 20,右翼定死像素,左翼 = 可用宽 − 净空 − 右翼。
  写死两翼像素,换一台刘海宽度不同的机器就会撞上刘海。

## 踩过的坑

**一、刘海里面画的东西肉眼看不见。** 刘海那块屏幕物理上不显示,但截图会把它当普通像素抓下来 ——
所以「截图里看得见」不等于「用户看得见」。静默条的内容必须落在刘海**两侧**那两截上。

**二、两翼没有 56 宽,只有 44。** `PillShape` 的顶角往外拐,侧墙在矩形边界往里缩一个顶角半径。
静默条顶角 12,所以肉眼可见的黑体只有 x ∈ [12, 283],按 56 排内容会有一截画在墙外面。
内容一律离墙 10 起算。

**三、第一下点击会被系统吃掉。** 刘海面板是不抢焦点的窗口,不重写 `acceptsFirstMouse`
的话,第一次点击只用来切焦点、不传给视图,用户得点两下。见 `FirstClickHostingView`。

**四、鼠标进出事件会漏。** 窗口尺寸刚变过、指针从别的空间切回来、指针一步跳到远处,
都可能只收到「进」收不到「出」,面板就永远以为鼠标还在上面,不自动收起。所以每半秒
拿真实指针位置校对一次(`AppState.startHoverAudit`)。

**五、`ISO8601DateFormatter` 默认不认毫秒。** 接口发的是 `2026-07-05T13:14:49.000Z`,
默认设置解出来是 nil,于是「该复习」一次都没亮过、静默条永远显示总数而不是到期数。
必须开 `.withFractionalSeconds`,再退回不带毫秒的解一次(`Card.parseTime`)。

**六、半屏面板的侧墙不在 frame 边上,而且两种机器不一样。** 就是第二条那件事在大面板上的样子:
`PillShape` 顶角往外拐,侧墙缩进**一个顶角半径**。没刘海的屏顶角是 40,900 宽的面板量出来
只有 x ∈ [92, 912] 是黑的;有刘海的屏顶角是 10 的肩膀,墙只缩 10。
所以这个数**只能算不能写死**(`AppState.contentSidePadding`)—— 写死 32 的时候,
没刘海的机器上左右各有 8 点内容被切掉,页脚的「在网页里打开」就少了半个字。

**六之二、页脚不能贴着下沿。** 下面两个角是 40 的圆角,**离底越近黑色的左右边界缩得越狠**:
离底 12 点的地方缩 11.4 点。页脚原来就贴在底边上,那一行字正好落在圆角弧线里,
看着就是「沾满了左下角右下角」。抬到离底 30 点(`Constants.footerBottomInset`),
弧线只剩 1.3 点,那一行才算站在直墙上。实测抬完左右各留出 17 点。

**七、合成鼠标事件抬手要不 warp。** 用 `CGEvent` 造拖放来验收时,最后那下
`leftMouseUp` 如果跟着 `CGWarpMouseCursorPosition` 一起发,会被拖拽会话自己的事件循环吃掉 ——
表现是「悬停高亮出来了、东西却没落地」,看着像 `onDrop` 没接住,其实是造事件的姿势不对。

**八、悬停小条的横向预算只够五个面。** 340 的内容宽减去方块 36、两道 12 的间距、
按钮排 118,正文只剩 162 —— 两行 13 号字大约二十四个汉字。**再加第六个面就不够了**,
到那时候要么按钮换成横滚,要么砍掉一个面,不能靠再挤一点。

**九、每次重新签名,系统权限就归零。** 临时签名的应用换一次构建就换一个签名,
日历权限从「已授权」退回「没问过」——`sqlite3 TCC.db` 里那一行还在,但对不上号了。
开发期间每次装新版都得重新点一次「现在就问我要」;要根治得有稳定的签名身份。

**十、没声明中文,日期就是英文的。** 界面通篇中文但 `Info.plist` 里没有 `CFBundleLocalizations`,
`Locale.current` 退回英文,日程面写出来是 "Thursday, Aug 6"。

## 手感是抄来的

尺寸、圆角、弹簧参数抄自 SuperIsland(见 `Sources/Core/Constants.swift` 里的注释)。
用户的要求是「效果和它一模一样」,手感就藏在这些数里,改任何一个都会偏。

形状那部分(`PillShape`)的关键是**顶部两角往外拐**:面板顶边贴着屏幕最上沿,
两侧的墙往下走之前先向外弯出去,和菜单栏那条黑边连成一体。普通圆角矩形做不出这个,
那样面板看着是浮在屏幕上的一块,而不是刘海长出来的。同一件事的另一半是 `NotchSeam`
那道压痕,和静默条**不打阴影** —— 静默条靠贴住屏幕顶边成立,底下垫一层模糊反而露馅。

## 还欠的

- 没有测试。纯计算的那几个(来源首字母、相对时间、读到第几节、番茄钟的跨天归零和
  重启续算)该有单测,现在没有测试目标。
- 推送还没做,还是 60 秒轮一次。
- 面板里画不了图(脑图、知识图谱),这是后面单独一件活。
- 番茄钟的 25/5 写死了,没有设置面板。原版可调 5–90 / 1–30。
- 截图只能认字存成笔记,图本身进不了知识库 —— 接口没有图片上传口,一张图也支撑不了引文。
- 日程只读不写,也不做会议链接识别(原版认 zoom / meet / teams)。
- AI 进程只接 Claude Code,不接 Codex(原版两个都接)。点一行是用 Finder 打开那个目录,
  不是跳回终端标签页 —— 那要能驱动 Warp / Terminal 的界面脚本,权限和适配是另一摊事。
- AI 进程不报「出错」。Claude Code 的钩子给不出可靠的出错信号(原版那个 `Error` 也只是
  给 Codex 用的、靠「一轮活没到 Stop 就没了」猜出来的),猜错了比不报更坏。
