# 传播面:分享卡 + 图谱生长回放

## 背景与目标

英语模式(#98)是为了在 X 上推广;这个 spec 给推广一个出口。两个功能:①任意知识卡/连接播报一键生成**分享图**(每张被分享的图都自带「每句有出处」的产品说明);②图谱**生长回放**(晒「我的第二大脑这个月长了多少」,对标跑步轨迹/GitHub 绿墙的空位)。纯 web 展示层,不碰存储、不碰 core 逻辑。

## 设计

### 1. 分享卡(web)

- 卡片操作区(PostView/PostDetailView)加「分享」按钮 → 弹层预览分享图 → 「下载 PNG」「复制到剪贴板」。
- **生成方式:零新依赖**。专用隐藏 DOM 节点渲染分享版式 → 序列化为 SVG `<foreignObject>` → 画到 canvas → PNG。KaTeX 公式、中文字体按浏览器实际渲染;若 foreignObject 路径在字体嵌入上不可行,降级方案:纯 canvas 手绘版式(标题/要点/出处行,公式区域用 KaTeX 渲染后的截图位图)。执行者二选一并在汇报里说明理由;**不引入 html-to-image 等新 npm 依赖**。
- 版式(贴 X 风格,深浅主题各一):标题、keyTakeaway、`来源 · N 处引文`(来源标题+日期,不放正文长引文)、右下产品标记(名字 + 一句「每句话都有出处」/ "every claim cited")、可选图谱一角(该卡概念的局部小图,复用 LinkedGraphCanvas 离屏渲染)。
- 语言跟随当前界面语言(i18n)。分享的内容就是卡上已有文本,不生成新文案(grounding:不造句)。

### 2. 图谱生长回放(web,GraphView)

- 图谱页加「回放」按钮:节点按其知识首次入库时间(概念最早卡片的 createdAt,数据现成)从 30 天前开始逐步出现,边随两端齐了浮现;底部时间刻度条可拖动;播完停在现状并显示「30 天:+N 概念 +M 连接」。
- 布局用当前 settle 后的最终坐标,只做出现动画,不重跑力导向(便宜且不晕)。
- 「导出对比图」:生成起点/终点两帧并排的 PNG(复用分享卡的导出管线)。动画导出 GIF/视频明确不做。

## 明确不做

- 不引入新 npm 依赖;不做服务端渲染图片。
- 不做 GIF/视频导出;不做一键发 X(用户自己贴图)。
- 不改 core、不改存储、不改 API(纯前端;若确需一个只读聚合端点,先回来问)。
- 不生成任何新文案性内容。

## 验证标准

1. `npm run typecheck` / `npm run build` / `npm test` 全绿(不该有 core/api diff)。
2. UI 截图(硬要求):含公式卡片的分享图 PNG 实物(深浅主题各一、中英各一)、回放中间帧、导出的对比图。
3. 分享图内容与卡片存储文本逐字一致(验收人抽查)。
