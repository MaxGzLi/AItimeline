# X 式主栏帖子详情页(废除右侧抽屉)

## 背景

现在点开帖子是右侧滑出 SourceDetailDrawer,与 X 的交互语法不符(用户明确反馈这是「很大的问题」)。X 的行为:点帖子 → 主栏切换到详情页(顶部返回栏),正文完整展开,下面接互动与回复;时间线里长正文折叠。

## 目标

1. **主栏详情页**:时间线点开帖子(或键盘 Enter)后,主栏整体切换为该帖详情页:
   - 顶部返回栏(← + 「帖子」标题,X 语法),点击或 Esc 返回,回到原滚动位置。
   - 详情页从上到下:作者行(头像/名字/@handle/认证徽章)→ 完整正文(双链照常渲染)→ 概念标签 → 原文出处引用块 → 时间与阅读时长行 → 操作行(评论/转发/赞/收藏)→ 评论线程(user_comment/agent_reply,含回复输入框)→ 问 AI(既有 grounded 问答,对话记录展示在线程里)。
   - 知识块(explain/example/quiz…)、图谱关系、复习与下一步、证据账本、反向链接:作为详情页正文下方的分区依次排列,风格沿用 X 扁平分隔(可用既有 drawer 分区的内容结构,但视觉上是主栏分区,不是侧栏卡片)。
2. **时间线正文折叠**:超过约 4 行的正文 clamp + 「显示更多」(蓝色行内链接,X 语法);点「显示更多」直接进详情页。
3. **SourceDetailDrawer 退役**:组件删除,其全部信息迁入详情页;xshell.css 中 drawer 专属样式清理(先全仓 grep 确认无引用再删)。
4. 右栏 rail(搜索/今日复习/知识边界/沉淀概念)保持不变;概念摘要面板(ConceptDigestPanel)交互不变。

## 不做

- 不引入路由库;详情页用现有 view state 实现(URL 深链记 v2)。
- 不动 packages/core、apps/api、apps/mobile(另一任务在改 core,严禁触碰)。
- 不改 dwell/信号上报逻辑,不改排序。

## 方案约束

- App.tsx 里 selectedCardId 既有状态可复用为「详情页路由」;打开详情页时主栏渲染 PostDetailView,时间线组件保持挂载或恢复滚动位置二选一,但返回后视口位置不得丢失。
- 键盘:Enter(聚焦帖)进详情,Esc 返回;j/k 在详情页内不生效。
- 样式仅用既有 --x-* token;不加阴影、渐变。
