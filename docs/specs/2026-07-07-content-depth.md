# 内容质量升级:知识块规格化 + 概念页成篇

## 背景与目标

真模型走查确认的第二优先级(用户原话:「知识块讲解太薄,阅读起来没有能拿走的东西」「概念节点解释不够丰富,进去看到的很干会很失望」)。诊断结论:

1. **知识块薄的根因一半在提示词、一半在上下文**。提示词只有格式清单(「必须含五种块」),无内容规格,模型填两句话交差;普通文章导入只喂前 4 片切片(`chunks.slice(0, 4)`),模型只见文章开头;userContext 类型存在但 source import 路径没填,「对比块」拿不到用户已知概念,只能写空对比。
2. **知识块在 grounding 校验里是 interpretation 级**(重叠不足只 warning 不毙卡)——有发挥空间,也有幻觉风险。要求写深必须配套「诚实标注」,否则模型用自身知识补,错了也溜进来。
3. **概念页只有卡片列表**,没有概念简介、没有关系说明、没有学习路径——「连成一整篇」的口号没兑现。
4. 小毛病:文章来源的切片显示「0:00」视频时间戳;`\(...\)` 形式的 LaTeX 不渲染;连接播报「你 0 天前学过的」应为「今天」。

## 设计

### 1. 知识块内容规格(core:提示词)

系统提示词 + hard requirements 里为五种块写内容规格与拿走标准:

- **讲解**:必须回答「它是怎么运作的 + 为什么这么设计」,禁止复述摘要;
- **例子**:带具体数字或场景走完整过程(输入→变换→输出);
- **对比**:与 **userContext 里用户已知概念**对比(没有已知概念时与来源内相邻概念对比),必须给出「什么时候用哪个」的判断;
- **延伸**:讲工程权衡或开放问题,禁止「未来可期」式空话;
- **小测**:考应用不考复述(给场景问决策,不问「X 是什么」)。
- 总标准写进提示词:「读完每块,用户要能带走一个能复述给别人的判断」;每块 body 给下限(zh ≥ 80 字 / en ≥ 60 words,schema 校验为 warning 不 error,避免硬卡死模型)。
- **诚实标注**:允许模型用自身通识补充,但超出来源的句子必须以 `[超出来源]`(en: `[beyond source]`)前缀标注,且超出部分禁止引入新数字、新专有名词事实(数字红线仍由现有硬门禁兜底,不改门禁)。
- 确定性 fallback 的模板同步按此规格加厚(达到字数下限、结构完整),smoke 网络隔离下必须过。

### 2. 上下文增厚(core + api)

- 普通文章导入的切片选择从 `slice(0, 4)` 改为**分桶相关性采样**:按文中位置分首/中/尾桶 + 概念命中优先,总上限 16 片(对齐论文路径的采样量,复用其实现思路)。
- source import 路径填充 `userContext`:用户已确认概念(点赞/收藏/提问涉及的)+ 薄弱概念(boundary learning 区)+ topicStates,由 api 在派卡任务时从快照取出传入。

### 3. 「来源内 / 超出来源」徽标(web)

- 知识块每条已有账本 overlap 状态(数据现成),UI 加小徽标:来源内(通过)/ 超出来源(warning);点徽标滚到证据账本对应行。零新数据,纯展示。

### 4. 概念页成篇(core + api + web)

- 概念页(点 #概念 打开的视图)顶部加**概念简介**区:它是什么、为什么重要、和你图谱里相邻概念的关系(用现有 graphEdges)、你的掌握进度(卡片数/复习次数,数据现成)。
- 简介生成:新的轻量任务 `concept_brief`,输入 = 该概念下所有卡的 keyTakeaway + 相邻概念 + 边关系;**引用规则**:简介每句话须可溯源到某张卡(卡 id 作为引用),复用现有 grounding 校验思路(interpretation 级);确定性 fallback 用模板拼装(「你从 N 张卡学到 X;它 requires A、extends B」)。
- 生成时机:概念页首次打开时惰性入队(占每日预算,防刷);生成前显示模板版,生成后替换并持久化到快照;概念下卡片数变化 ≥3 张后标脏、下次打开重新生成。
- 卡片列表排序:按图谱 requires 链拓扑序(先决概念的卡在前),同层按 createdAt。
- **延伸块尾部加「就这个点问下去」按钮**(web):把延伸块内容预填为问题,走 #100 提问闭环管线(显式动作,不占预算)。

### 5. 小修(web)

- 来源片段:非视频来源不显示时间戳(`startTimeSeconds` 未定义或来源类型非视频时显示序号);默认折叠(显示前 2 片 + 「展开全部 N 片」),每片顶部不加导读(导读依赖生成,留给后续)。
- 公式渲染:`\(...\)` / `\[...\]` 归一化为 `$...$` / `$$...$$` 后再渲染。
- 连接播报文案:「0 天前」→「今天」,「1 天前」→「昨天」(i18n 双语)。

## 明确不做

- 不改 grounding 门禁的阈值与数字红线。
- 不做概念页手动编辑简介;不做学习路径的一键批量生成(那是「主题包」,另立项)。
- 不动时间线生命周期、推荐排序。
- 不引入新 npm 依赖。
- 不回填存量卡(新规格只作用于新生成;存量卡用户看到的仍是旧内容)。

## 验证标准

1. `npm run typecheck` / `npm run build` / `npm test` 全绿。
2. smoke 扩展(硬要求):
   - 确定性 fallback 的知识块达到字数下限且五块齐全;
   - 文章 fixture 导入时模型输入包含 >4 片切片(断言采样数);
   - userContext 里含 fixture 预置的用户概念;
   - concept_brief 确定性路径产出模板简介且每句可溯源;
   - `\(...\)` fixture 渲染为 KaTeX(web 无单测,断言归一化函数)。
3. UI 截图:知识块带徽标、概念页成篇(简介+排序列表)、来源片段折叠态、文章切片无 0:00。
4. 模型路径:汇报附一次真实生成的知识块实录,验收人在沙盒抽查「超出来源」标注与字数。
