# 视觉校准:对齐真 X(lights-out)观感

## 背景

用户发来 x.com 暗色主页截图:「感觉还是这个好」。色板 token 已是 X 精确值,差距在布局比例、密度和模块质感。逐项对比出五处差异(见下)。UI 改动由主会话执行。

## 目标(与真 X 的差异逐项对齐)

1. **三栏整体居中**:`.x-frame` 由贴左(`justify-content: start`)改为居中;列宽 `84px 600px 384px` → `275px 600px 350px`(X 实际比例)。
   - 注意:「贴左布局」是早前定的方向,本次依据用户新指示(真 X 截图)改为居中,PR 里显著标注,可一行改回。
2. **左导航 X 式宽导航**:图标 + 文字标签(时间线/发现/图谱/复习/智能体/设置),行高 padding 12px、文字 20px、active 加粗;底部大「发帖」主按钮(暗色下白底黑字,即 `--x-btn-bg/--x-btn-ink`),宽度约 90%、高 52px。
   - 响应式:≤1300px 收窄为 88px 纯图标(现状样式);≤1120px 隐藏右栏。
3. **右栏模块质感**:暗色下模块由灰底填充(#16181c)改为**纯黑底 + 1px 描边**(X lights-out 的做法);亮色保持 #f7f9f9 填充不带边(X 亮色的做法)。搜索框暗色用 X 的 #202327。`.x-module-head` 补 `margin: 0`(顺带消掉 h2 默认外边距造成的头部空隙)、字号 19→20px。
4. **密度**:`.x-frame` 行高 1.5 → 1.3333(X 的 15px/20px)。
5. **主栏头部**:时间线视图只显示标签页(去掉「时间线」标题行,X 主页即如此);`.x-colhead` 改半透明 + `backdrop-filter: blur`(毛玻璃粘性头)。
6. **主按钮**:composer 的「发布」(.x-pill)改用 `--x-btn-bg/--x-btn-ink`(暗色白底黑字,新 X 的标志性做法)。

## 不做

- 不动信息架构、卡片内容结构、详情页布局、mobile。
- 不加「显示 N 帖子」一类 X 专有装饰行。
- 不改 packages/core / apps/api。

## 验收清单

- [ ] 2000×1100 暗色截图:三栏居中、宽导航带标签、白色发帖按钮、右栏描边模块——与 x.com 截图并排看气质一致
- [ ] 亮色截图不回归(模块仍灰底、按钮黑底白字)
- [ ] 1280px 窗口:导航收为纯图标不破版
- [ ] 详情页右栏(#79 修复)不回归

## 假设(用户可推翻)

- 居中布局取代贴左(依据:用户认可的真 X 截图是居中的)。
- 「发帖」按钮点击行为沿用现状(聚焦 composer)。
- 三个标签(推荐/最新/已收藏)保留,不砍成 X 的两个。
