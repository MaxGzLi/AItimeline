# 多主题编排:成块、主题 pill、停留兴趣与生产保底

## 背景与目标

用户有多个跨度大的学习主题时,单一混排流逐卡跳频,上下文切换成本最高。用户定案:**新内容成块(blocking)+ 复习穿插(interleaving)+ 主题 pill 做逃生舱 + 生产预算每目标保底**;并采纳用户补充:**块级停留时长推断「今日兴趣」**,让当天的排序跟着当下的兴趣走。

侦察事实:`InteractionSignal.dwellTimeMs` 字段与 ranker 的「停留 ≥12s 加分」逻辑均已存在,但 web 曝光上报恒发 0(apps/web/src/lib/state.ts:49),死字段;卡片已有 `topicId`;active 学习目标已有闭包概念集(#111)。

## 设计

### 1. 主题簇归属(api 组装层,确定性,零模型)

- 每张时间线卡归属一个 `blockTopic`:优先 active 学习目标(卡概念归一后命中该目标闭包,多目标命中取进度最落后者);未命中任何目标 → 用卡自身 `topicId`。
- 纯函数,可 smoke。

### 2. 成块重排(core:ranking 新纯函数 `arrangeTimelineBlocks`)

- 输入 ranker 排序后的卡列表 + 每卡 blockTopic + 当日主题停留聚合;输出块结构。
- **新内容卡**按 blockTopic 分组,每块 3~4 张(同主题不足 3 张则成短块,不硬凑);块与块交替不同主题。
- **复习到期卡与连接播报不进块**,保持 ranker 原相对位置穿插(复习穿插有记忆科学依据,明确保留)。
- **块序**:基础按块内最高分;加「今日兴趣」调整——当日(UTC 自然日)signals 按 blockTopic 聚合 `sum(dwellTimeMs)`,停留占比高的主题块前移(实现:块分 = 块内最高分 + min(30, 当日该主题停留分钟数 × 6);系数常量不配置)。只影响块序,不改单卡分数与理由,当日有效不持久化,防反馈回路。
- 每块附 `divider` 元数据(主题名),确定性排序,同输入同输出。

### 3. 主题 pill(web)

- 时间线顶部 pill 行:「全部」(默认)+ 按当前时间线出现的 blockTopic 生成(active 目标簇优先,总数上限 5,余下归「其他」);点选为**前端过滤**当前已加载列表,不打 API、不持久化。
- X 风格胶囊,复用 `.x-tab`/`--x-*` 语言,贴左;i18n 双语。

### 4. 停留时长真实上报(web)

- PostView 已有可见性观察(曝光判定);累计每张卡的**实际可见时长**填入 `dwellTimeMs`(单卡上限 120000ms 截断,防挂机/后台标签),随既有 /api/signals 上报,信号形状不变。
- 效果一:ranker 既有 dwell≥12s 奖励即刻生效;效果二:§2 的当日主题停留聚合有了真数据。

### 5. 生产保底(api)

- 后台策展计划分配每日预算时,**每个 active 学习目标每天至少获得 1 个生产名额**(该目标的 gap concept_brief 或闭包内 followup,取既有管线现成的需求);目标当天已有对应生产则视为已满足;无可生产需求(无 gap、无 followup 候选)不强造。在预算内优先扣位,不增加预算总量。

## 明确不做

- 不做「今日焦点轮换」与分区 tab(C/D 方案);
- 不做图谱社区发现聚类(主题簇只用 目标闭包 + topicId);
- 不做停留数据的可视化/统计页;pill 选择不持久化;
- 不改复习调度、门禁、预算总量、ranker 单卡打分逻辑本身(只消费其输出);
- 零模型调用;不引入新 npm 依赖。

## 验证标准

1. `npm run typecheck` / `npm run build` / `npm test` 全绿(网络隔离)。
2. smoke-core:`arrangeTimelineBlocks` 纯函数断言——分块 3~4 与短块、复习卡/连接播报穿插原位、块序基础分、今日停留把冷主题块推前、确定性(同输入同输出)、blockTopic 归属(命中目标闭包/回落 topicId/多目标取落后者)。
3. smoke-api:timeline 响应含块结构与 divider;当日 signals 注入停留后块序变化;生产保底——两个 active 目标下每日计划各至少 1 名额、预算内扣位、无需求不强造、重复运行幂等。
4. UI 截图(验收人):块分隔与 pill 行(浅色+深色)、pill 过滤态、停留上报的 payload 抓包(dwellTimeMs 非 0)。
5. 真实数据验收(验收人):真实快照下块结构合理;阅读若干卡后当日兴趣聚合非零且块序响应。
