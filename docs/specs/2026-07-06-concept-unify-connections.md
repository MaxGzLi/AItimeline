# 概念归一 + 连接播报:把知识串起来,只在值得「哦!」的时刻开口

## 背景与问题

概念现在是字符串级的:「投机解码」「speculative decoding」「Speculative Decoding」是三个图谱节点。放任下去:图谱碎片化、同一知识多头计数、任何「连接播报」功能都会被相似节点刷成 SPAM。同时,新知识与旧知识连接是这个产品最独特的爽点,目前完全没有呈现——连接静默地画在图谱里,用户从不知道。

原则:**名字只是线索,证据才是依据**(合并判断必须比对概念背后的卡片内容);**播报宁缺毋滥**(预料之中的连接一律沉默)。

## 设计

### A. 概念归一(core:graph/ 新模块 conceptAliases)

1. **数据**:快照新增 `conceptAliases: Array<{ canonical: string; aliases: string[]; decidedBy: "auto" | "user"; decidedAt: string }>`。图谱构建、排序、复习、播报处对概念先过 `resolveConcept(name)` 归一;**存储的卡片文本一个字不改**(展示与统计层归一,grounding 红线)。
2. **自动合并(保守,只做无争议的)**:大小写/全半角/首尾空白差异;既有别名表命中。仅此两类自动 merge。
3. **模型辅助判定(可选路径)**:候选对(名字编辑距离近、或共享 ≥2 张卡)→ 取各自挂的卡片摘要作为「定义证据」,让模型判 same / different / uncertain;same → 生成**合并建议**(不直接合);无模型时此路径整体跳过——确定性行为是「只做第 2 条的机械合并」。
4. **合并建议交给用户**:图谱页顶部一条低调横幅「这两个可能是同一个概念:A / B(各附一句定义摘录)——合并 / 分开」;用户点了才生效,决定写进 conceptAliases(decidedBy: user),同样的对不再重复问。提供解除合并入口(别名表里移除)。
5. **来路**:概念详情(图谱侧栏)显示:首次入库时间、来自哪张卡;若该卡来源带 origin(spec ① 落的数据),显示「由你 M 月 D 日的提问带入」。

### B. 连接播报(core 生成 + api 落库 + web 呈现)

1. **触发**:一次导入批次完成后(import / research 管线收尾处),对新卡产生的图谱边计算新奇度,达标则生成**一条**播报(整批合并,绝不逐边发)。
2. **新奇度门槛(全部确定性,可离线)**,满足其一才播:
   - **远簇接通**:新边两端概念在旧图谱中的最短路径 ≥3 跳(或原本不连通);
   - **唤醒**:边的另一端概念,其全部卡片 ≥14 天无任何交互信号,或该概念的卡在退场列表(用 spec ④ 的 dismissedPosts 数据);
   - 边任一端是**高度数枢纽**(度数前 10% 的节点,如 LLM/AI Agent)→ 直接否决,不参与以上判定。
3. **限流**:每天最多 2 条播报;超出的丢弃(不排队,过时的「哦」不值得补发)。
4. **形态**:播报是一条特殊时间线卡(新 kind `connection_note`),文案模板:「你 N 天前{收藏/学过}的《旧卡》和刚导入的《新卡》连上了:{关系}」——关系文本用 graphEdge 的 evidence(已有出处数据),不新造文本;引用两张卡可点开;若属「唤醒退场卡」,附「请回时间线」按钮(调 spec ④ 的 undismiss)。确定性回退:无模型时文案纯模板拼接,可用。
5. 播报卡参与正常生命周期(可 ✕、不进复习)。

## 明确不做

- 不做矛盾检测/知识保鲜(单独立项,涉及断言级比对,别塞进来)。
- 不做每周长势回顾。
- 不自动合并任何有语义争议的概念对;uncertain 一律不打扰用户(攒着,只在图谱页横幅一次一条)。
- 不改动已存储卡片、来源、引文文本。
- 不动通知系统(播报走时间线卡,不走 spec ① 的通知)。

## 验证标准

1. `npm run typecheck` / `npm run build` / `npm test` 全绿。
2. smoke-core 扩展断言(硬要求):机械归一(大小写/空白)生效且卡片文本未变;别名表命中归一;resolveConcept 幂等;远簇/唤醒/枢纽否决三条规则各一个构造用例;整批只产一条播报;每日限流;播报文案含两张卡引用与 evidence 文本。
3. smoke-api:导入触发播报卡入快照;undismiss 按钮数据完整;合并建议写入与解除。
4. UI 截图:播报卡(时间线里)、图谱合并建议横幅、概念详情来路。i18n zh/en 成对。
