# 黑客松五天冲刺计划

日期:2026-08-04 定稿。提交日按「今天 + 5 天」= 2026-08-09,以官方截止时间为准。

## 一句话目标

用三分钟演示讲完闭环:**刷 X 时顺手捡知识(剪藏)→ 知识变成带出处的卡回到你的信息流(注入)→ 桌面基地里 agent 替你沉淀串联(台账+对话)→ 学到的东西排成可发布的图文(出口)。**

进不了这三分钟的功能,赛前一律不碰。已建的复习/周报/深读/技能树留作评委追问时的弹药,不进主线。

## 三分钟演示线

1. 打开 X 正常刷(评委秒懂的摸鱼场景)。
2. 刷到一条有价值的推文,插件一键保存。
3. 几秒后它变成一张带出处的知识卡(可当场点开看引用)。
4. 继续刷,信息流里混进一张和 X 帖子长得一样的卡——三天前存的知识回来找你了。
5. 切到桌面基地:第一屏是 agent 台账「这周替你捡了 N 条、串出这片图谱、明天送回 M 条」。
6. 对 agent 说一句「我最近想搞懂 ___」,它当场调整策展方向。
7. 收尾:一键把本周所学排成小红书图文,能直接发。「它不光帮你学,还把你学的变成你的内容。」

## D1 注入验证结论(2026-08-04 实测,拍板:真注入)

在真实登录的 x.com 时间线上实测通过,不需要降级:

- **X 时间线结构**:每条推文在 `div[data-testid="cellInnerDiv"]` 里,绝对定位 + `translateY` 排版,容器 `position:relative; min-height` 撑高,同屏只挂 ~17-22 个格子(虚拟列表)。
- **插法**:把卡 `prepend` 进某个格子内部(不能当兄弟节点插)。X 自己会测量格子高度变化并重排整列(实测:格子 665→782px,下一格 translateY 2718→2835px,自动让位,不重叠不破版)。
- **滚动存活**:格子滚远即被回收,滚回来时 React 重建格子,裸插的卡会丢(实测确认)。解法:以推文的 `/status/` 链接为锚点 + `MutationObserver` 监听容器 childList,格子重建时自动补插,插前查重。实测:滚远 16000px 再回来,卡在原位、恰好一份。
- **原生外观要素**:字体继承(PingFang SC),分隔线 `rgb(47,51,54)`,次要文字 `rgb(113,118,123)`,链接蓝 `rgb(29,155,240)`,头像 40px 圆形,内边距 12px 16px。
- 演示模式(写死卡)的兜底保留,但按当前结论用不上。

**D1 决策记录之二(用户拍板,真机验收发现)**:概念接地检查跨语言降为警告——概念是拉丁文、引用证据全部是中日韩文时,「概念必须逐字出现在证据里」从拦卡降为警告(沿 #152 事实句分流先例,全摄入道生效);同语言缺失照旧硬拦。背景:真机剪藏两条中文推文均死于此检查,纯中文推文结构性出不了卡,中文场演示必翻车。

**D1 决策记录(用户拍板)**:剪藏道(browser_share)豁免内容深度门禁——用户亲手点保存本身就是质量信号,产品不拦用户自己要的东西;agent 自动发现的来源照常过门禁,拦垃圾的初衷不受损。背景:实测 280 字典型短推文 0.44 分差阈值 0.45 一线被拒。D2(任务 #3)实现。

## 三分钟台词初稿(D4 定稿,先给用户过目)

> 【开场,20 秒,放一张普通的 X 信息流】
> 在座各位今天在 X 上刷了多久?一小时?两小时?留下了什么?大部分人的答案是:一点模糊的印象,和一点焦虑。我们不打算劝你少刷——我们让你刷过的时间留下东西。

> 【第一幕:捡,60 秒,现场操作】
> 这是我的 X,正常刷。看到这条讲 RLHF 的好推文——点一下这个保存键。好了,继续刷。(切到基地)几秒钟后,它在我的知识库里变成了这张卡:不是复制粘贴,是提炼过的知识点,每句话都标着出处,点开就能对回原文。我们管这个叫「顺手捡」。

> 【第二幕:回来,40 秒,继续刷 X】
> 更重要的是三天后。我还在刷 X,刷着刷着——这条不是推文,是我三天前存的知识,自己回来找我了。样子和 X 的帖子一模一样,不打扰,刷到就是复习,划过也没关系,它下次还会来。学习不需要打开任何新 App,它长在你已有的习惯里。

> 【第三幕:基地,40 秒,切到桌面应用】
> 这些东西沉在哪?这个桌面应用是它的基地。打开第一眼不是聊天框,是我的 agent 这周替我干了什么:捡了 47 条、串出了这片概念图、明天准备送 3 条回我的信息流。我跟它说一句「我最近想搞懂强化学习」——它听懂了,之后往我信息流里送的东西就会朝这个方向走。

> 【第四幕:出去,30 秒,点一个按钮】
> 最后,学到的东西不该锁在库里。一键,agent 把我这周学的排成一组能直接发的小红书图文。刷进来的是别人的内容,发出去的是你自己的知识。

> 【收尾,10 秒】
> 你刷掉的时间,捞回来了。内核开源,今天就能自己跑。谢谢。
