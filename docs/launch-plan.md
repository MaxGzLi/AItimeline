# Launch Plan

## Phase 1: Prototype

- Build a static Web UI with realistic knowledge cards.
- Implement core card, ranking, graph and review types.
- Manually seed high-quality AI knowledge content.
- Interview 10 to 20 target users.

## Phase 2: Private Alpha

- Add source connectors and agent runs.
- Add AI card comments.
- Add account and persistence.
- Invite 50 to 100 users from AI/product/learning communities.

## Phase 3: Paid Beta

- Add quota, billing and Pro plan.
- Add BYO key mode.
- Add weekly briefings and review queue.
- Publish the open core repo with clear commercial boundaries.

## Phase 4: App

- Build native or hybrid mobile app after payment signal is clear.
- Focus on timeline speed, notifications and review moments.
- Keep advanced agent configuration on Web first.
