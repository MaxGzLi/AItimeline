# Brand And UI Direction

## Interface Direction

The product can borrow the familiar three-column information architecture:

- left navigation
- center timeline
- right context rail

But it should not copy X's visual identity, logo, exact icons, metadata, interaction wording, or trade dress.

## Product Feel

- Dense enough for repeated daily scanning.
- Calm, research-oriented, and fast.
- More like a personal intelligence desk than a public social network.
- Cards should show sources and uncertainty clearly.

## Key Screens

- Timeline
- Knowledge Card Detail
- AI Comment Thread
- Topic Agent Settings
- Knowledge Graph
- Review Queue
- Billing and Usage
