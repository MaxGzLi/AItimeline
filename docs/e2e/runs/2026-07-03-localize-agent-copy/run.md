# 全量中文化观察员文案

日期:2026-07-03
分支:`chore/localize-agent-copy`

## 目的

产品 UI 已是中文,但观察员(agent)的确定性回答、动作按钮标签、发现候选理由、反馈闭环理由等仍是英文。本次把这些用户可见的英文模板改成平实自然的中文。

## 截图

`agent-reply.png`:在发帖框点「RAG 和微调该怎么选?」示例问题并发布后,观察员给出的中文回帖。

可以看到:
- 边界标签「这个问题在你的学习区」。
- 确定性回答骨架已中文化:「根据《…》:…」「依据:…」「你的问题是:「…」。」引文原文保持不变。
- 动作按钮为中文:「深入了解一下」「换个更简单的说法」等。

## 说明

时间线下方卡片仍有英文正文,那是从英文的演示来源(YouTube/文章)按出处生成的知识卡内容,不是 UI 模板文案;翻译它会破坏 grounding 重叠校验,因此不在本次范围内。

## 验证

`npm run typecheck && npm run build && npm test` 全绿;三个 smoke(core / api / model)均通过,grounding 校验仍有效。
